Buyer’s format guide

Format overview

The 30×60 collection is intended for bathroom, kitchen and wall-or-floor design schemes. It is a rectangular format suitable for horizontal or vertical layouts depending on the selected model specification. Available appearance, surface finish and technical performance depend on the selected factory model.

Model selection

Buyers can request current marble-look, stone-look, concrete-look, wood-look, polished or matte options when available for this format. A visual reference is useful, but approval should also consider the intended space, installation method and the model’s technical data.

Information to confirm before quotation

  • Factory and model code.
  • Porcelain or ceramic body.
  • Surface finish, shade and calibre.
  • Thickness and technical rating for the intended application.
  • Pieces and square metres per carton.
  • Carton and pallet weight, container quantity and packing method.
  • Current production status, lead time and available documentation.

Export enquiry

Send the required quantity, destination country, preferred finish and model numbers. LuxeCeram can coordinate suitable options, sample discussion, packing details and FOB or CIF quotation. No technical value or delivery date should be treated as final until it is confirmed for the selected model.
